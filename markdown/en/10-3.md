## **10.3 Basic Computer Components**
### **10.3.1 [Computer hardware](https://en.wikipedia.org/wiki/Computer_hardware)**
- [Logic family](https://en.wikipedia.org/wiki/Logic_family) (Logic circuit), [Logic gate](https://en.wikipedia.org/wiki/Logic_gate) (→ 3.2.2 Logic)
- [Semiconductor](https://en.wikipedia.org/wiki/Semiconductor), [Transistor](https://en.wikipedia.org/wiki/Transistor), [Integrated circuit](https://en.wikipedia.org/wiki/Integrated_circuit)
- Five major components of a computer (Basic hardware classification in [Von Neumann architecture](https://en.wikipedia.org/wiki/Von_Neumann_architecture))
    - Input device: [Input device](https://en.wikipedia.org/wiki/Input_device) (keyboard, mouse, sensors, etc.) (→ 1.2.2.4 Observation)
    - Output device: [Output device](https://en.wikipedia.org/wiki/Output_device) (display, printer, speakers, actuators, etc.)
    - Storage device: [Main memory](https://en.wikipedia.org/wiki/Computer_memory), Auxiliary storage, [Processor register](https://en.wikipedia.org/wiki/Processor_register), Cache memory, [Memory hierarchy](https://en.wikipedia.org/wiki/Memory_hierarchy) (→ 1.2.3.1 Recording)
    - Arithmetic logic unit: [Arithmetic logic unit](https://en.wikipedia.org/wiki/Arithmetic_logic_unit)
    - Control unit: [Control unit](https://en.wikipedia.org/wiki/Control_unit)
	    - [Central processing unit](https://en.wikipedia.org/wiki/Central_processing_unit) (CPU), [Graphics processing unit](https://en.wikipedia.org/wiki/Graphics_processing_unit) (GPU)
- [Instruction pipelining](https://en.wikipedia.org/wiki/Instruction_pipelining), [Parallel computing](https://en.wikipedia.org/wiki/Parallel_computing), [Distributed computing](https://en.wikipedia.org/wiki/Distributed_computing)
- Data communication (→ 1.2.2 Communication and Telecommunication)
	- [Memory model (programming)](https://en.wikipedia.org/wiki/Memory_model_(programming))
	- [Memory ordering](https://en.wikipedia.org/wiki/Memory_ordering)
	- [Data migration](https://en.wikipedia.org/wiki/Data_migration)
- Implementation of computers based on non-silicon substrates (→ 10.3.4 Non-von Neumann computers)
