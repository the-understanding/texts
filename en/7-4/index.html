    7.4 Model Evaluation and Interpretation

    7.4 Model Evaluation and Interpretation

    7.4.1 Model Evaluation

    7.4.1.1 Evaluation Methodology

    • Experimental verification
    • Evaluation metrics in statistics and machine learning

    7.4.1.2 Indicators of Prediction Error

    • Goodness of fit, Coefficient of determination, Partial fit and overall fit
    • Mean squared error (MSE), Root-mean-square deviation (RMSE), Mean absolute error (MAE)

    7.4.1.3 Indicators of Classification Performance

    • Confusion matrix (Precision and recall)
    • F-score, Sensitivity and specificity, Receiver operating characteristic

    7.4.1.4 Indicators Based on Similarity and Information Content

    • Metric space, Cosine similarity
    • Kullback–Leibler divergence, Cross entropy
    • Loss function

    7.4.1.5 Model Selection and Complexity

    • Cross-validation (statistics)
    • Goodness of fit, Model selection criteria (Akaike information criterion, Bayesian information criterion, Watanabe–Akaike information criterion)
    • Overfitting, Regularization (mathematics)
    • Occam's razor, Solomonoff's theory of inductive inference
    • Curse of dimensionality

    7.4.1.6 Limitations of Data and Models

    • Missing data
    • Feature (machine learning)
    • Data observational error, random error, systematic error (→ 6.4.4.1 Observational error)
    • Confounding, Covariates (→ 7.2.3 Variables and Parameters)

    7.4.2 Model Interpretation

    7.4.2.1 Interpretability and Uncertainty

    • Explainable artificial intelligence (→ 10.4.2 Generative AI and Social Impact)
    • Sensitivity analysis (analysis of the effect of changes in inputs/assumptions on the output)
    • Local optimum, Global optimum
    • Stability of solution, Steady-state solution
    • Approximation / Exact solution

    7.4.2.2 Bias and Distortion

    • Bias (→ 9.4.3 Bias, Fallacy, Sophistry)
      • Sampling bias, Coverage error
      • Cognitive bias
      • Interpretation bias
        • HARKing
        • Data dredging, Data dredging
        • Threshold-setting bias, Fault tolerance
      • Spurious relationship
      • Extrapolation
      • Simpson's paradox

    7.4.2.3 Model Learning and Evaluation

    • Relationship between data volume and model accuracy, Learning rate
    • Reward hacking (→ 10.4.2 Generative AI and Social Impact)
    • Data reproducibility, Analysis reproducibility
    • All models are wrong

    7.4.3 Model Improvement and Update

    • Model update
      • Machine learning (→ 7.3.3 Machine Learning and Deep Learning)
      • Reinforcement learning (→ 7.3.2 Typology by Model Construction Procedure)
      • Transfer learning, Model generalization
      • Online machine learning (Adaptation to non-stationarity of data distribution)
      • Fine-tuning (deep learning)
      • Improvement through multiple models: Ensemble learning (Bagging, Boosting)
    • Improvement of data quality, Imputation of (missing) data
      • Training, validation, and test data sets
    • Model refinement, generalization, model retraining
    • Model degeneration, lightweighting
    • Model destruction
      • Model collapse
      • Catastrophic interference
      • Anomaly
