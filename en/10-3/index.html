    10.3.1 Computer hardware

    • Logic family (Logic circuit), Logic gate (→ 3.2.2 Logic)
    • Semiconductor, Transistor, Integrated circuit
    • Five major components of a computer (Basic hardware classification in Von Neumann architecture)
      • Input device: Input device (keyboard, mouse, sensors, etc.) (→ 1.2.2.4 Observation)
      • Output device: Output device (display, printer, speakers, actuators, etc.)
      • Storage device: Main memory, Auxiliary storage, Processor register, Cache memory, Memory hierarchy (→ 1.2.3.1 Recording)
      • Arithmetic logic unit: Arithmetic logic unit
      • Control unit: Control unit
        • Central processing unit (CPU), Graphics processing unit (GPU)
    • Instruction pipelining, Parallel computing, Distributed computing
    • Data communication (→ 1.2.2 Communication and Telecommunication)
      • Memory model (programming)
      • Memory ordering
      • Data migration
    • Implementation of computers based on non-silicon substrates (→ 10.3.4 Non-von Neumann computers)

    • Abstraction (computer science), Module (→ 5.2 Structure of a System), API

    • Input/output

    • Zero-knowledge proof, Secret sharing, Secure multi-party computation
